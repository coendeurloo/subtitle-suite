# Subtitle Suite - Beta 0.9.5

Release date: 2026-08-04

## Highlights

- Recognizes numbered language variants such as `Movie.ru2.srt`.
- Resolves duplicate subtitle candidates by comparing their timing against the other selected language.
- Fixes the Baron Munchausen case where the shifted `ru.srt` was selected instead of the correctly aligned `ru2.srt`.
- AI translation keeps the canonical target subtitle active and archives superseded same-language variants in `DualSubtitles`.
